--------------------------------------------------------------
 WINDOWS (10/11)
--------------------------------------------------------------
 1. Giải nén file anhcuoi-windows.zip ra một thư mục
    (vd D:\ThiepCuoi). KHÔNG chạy trực tiếp trong file .zip.
 2. Mở thư mục anhcuoi vừa giải nén, bấm đúp run_window.bat
    - Windows hỏi "Windows protected your PC": bấm "More info"
      -> "Run anyway".
    - Lần đầu có thể cần cài Microsoft Visual C++ Redistributable
      (thư viện PHP cần): script tự tải và cài, bạn chỉ cần bấm
      Yes khi Windows hỏi. Máy không tự tải được thì tải tay:
        https://aka.ms/vs/17/release/vc_redist.x64.exe
      cài xong rồi bấm đúp run_window.bat lần nữa.
 3. Trình duyệt tự mở trang cài đặt. Không tự mở thì gõ địa chỉ
    in trong cửa sổ đen (dòng "May nay : http://localhost:...",
    thường là http://localhost:8686).
 4. Điền tên chú rể, cô dâu, ngày cưới, tạo mật khẩu quản trị
    -> bấm "Tạo trang cưới".
 5. Chờ khoảng 1 phút: link https://xxxx.jagame.vn hiện ở
    Quản trị -> "Gửi link & QR".

--------------------------------------------------------------
 macOS  -  cần PHP (cài 1 lần)
--------------------------------------------------------------
 1. Mở ứng dụng Terminal, cài Homebrew (nếu chưa có) theo
    hướng dẫn ở https://brew.sh rồi gõ:
        brew install php
 2. Trong Terminal gõ:
        cd ~/Downloads
        unzip anhcuoi-mac-linux.zip        (tạo thư mục anhcuoi)
        cd anhcuoi
        bash run_mac.sh
    Nếu trong Downloads đã có thư mục anhcuoi (Safari tự giải
    nén khi tải về) thì bỏ qua lệnh unzip, gõ tiếp từ "cd anhcuoi".
 3. Trình duyệt tự mở trang cài đặt (không tự mở thì gõ địa chỉ
    in trong cửa sổ Terminal, thường là http://localhost:8686)
    rồi làm như bước 4-5 của Windows.

--------------------------------------------------------------
 Linux (Ubuntu/Debian)
--------------------------------------------------------------
        sudo apt install php-cli php-sqlite3 php-gd php-zip php-curl php-mbstring curl unzip
        unzip anhcuoi-mac-linux.zip && cd anhcuoi
        bash run_mac.sh
    Mở trình duyệt vào địa chỉ in trên màn hình (thường là
    http://localhost:8686) và làm như bước 4-5 của Windows.

--------------------------------------------------------------
 SAU KHI CÀI
--------------------------------------------------------------
 - Sửa trang: vào địa chỉ in trong cửa sổ chương trình (thường
   là http://localhost:8686), bấm vào chữ/ảnh có
   viền nét đứt để sửa; chọn 1 trong 10 giao diện ở thanh dưới.
 - Bấm "Cho khách xem" để khách mở được trang.
 - Khách mời: Quản trị -> Khách mời -> thêm khách -> mỗi người
   có thiệp riêng (vd https://xxxx.jagame.vn/co-chu-lan-hung)
   -> bấm "Gửi thiệp" để gửi qua Zalo/Messenger.
 - Muốn tên đẹp như minh-lan.jagame.vn: Quản trị -> "Gửi link
   & QR" -> gửi yêu cầu tên riêng (được duyệt là tự đổi).
 - Máy tính phải BẬT và chương trình phải CHẠY thì khách mới
   xem được trang (ảnh nằm trên máy bạn). Tắt cửa sổ = trang
   tạm ngừng; chạy lại là link cũ hoạt động tiếp.

--------------------------------------------------------------
 DỪNG / NÂNG CẤP / SAO LƯU
--------------------------------------------------------------
 - Dừng: bấm Ctrl+C trong cửa sổ chương trình, hoặc đóng cửa sổ
   đó. Khách sẽ tạm không mở được trang cho tới khi chạy lại.
 - Nâng cấp lên bản mới: dừng chương trình, giải nén bản mới
   ĐÈ LÊN thư mục cũ (chọn "Thay thế tất cả"). Dữ liệu nằm ở 3
   thư mục database/, uploads/, cloudflared/ và được giữ nguyên.
   Chạy lại như bình thường; link cũ vẫn dùng tiếp.
 - Sao lưu: dừng chương trình rồi chép 3 thư mục database/,
   uploads/, cloudflared/ ra ổ khác hoặc USB. Khôi phục: cài bản
   mới rồi chép 3 thư mục này đè vào.

--------------------------------------------------------------
 GẶP LỖI?
--------------------------------------------------------------
 - Windows báo "VCRUNTIME140.dll was not found" / "không tìm
   thấy VCRUNTIME140.dll": máy thiếu Microsoft Visual C++. Chạy
   lại run_window.bat (tự cài), hoặc tải tay link ở mục WINDOWS.
 - "Cổng 8686 đang bận": chương trình đang chạy ở cửa sổ khác,
   hoặc tự đổi sang 8687 - xem địa chỉ in trong cửa sổ.
 - Linux báo "PHP thiếu tiện ích": chạy đúng lệnh apt in trên
   màn hình rồi chạy lại bash run_mac.sh.
 - Link jagame chưa hiện sau vài phút: kiểm tra Internet;
   trang tự thử lại (trong lúc chờ có link tạm trycloudflare).
 - Chương trình bị treo / không mở được: chạy reset_win.bat
   (Windows) hoặc bash reset_mac.sh (macOS/Linux) rồi chạy lại.
   Lệnh này chỉ tắt Ảnh Cưới của thư mục này, không đụng chương
   trình khác và không xóa dữ liệu.
 - Quên mật khẩu quản trị: mở cửa sổ lệnh TRONG thư mục chương
   trình rồi chạy
     Windows : php\php.exe index.php cli doi_mat_khau
     macOS   : php index.php cli doi_mat_khau
   Máy hỏi mật khẩu mới 2 lần (ít nhất 8 ký tự). Trên macOS/Linux
   khi gõ mật khẩu sẽ không hiện chữ, đó là bình thường. Trên
   Windows chữ có hiện — đừng để người khác nhìn màn hình.
   Tên đăng nhập giữ nguyên; mọi nơi đang đăng nhập sẽ bị đăng xuất.
 - Vừa cập nhật từ bản cũ, ảnh trên điện thoại tải chậm: chương
   trình tự tạo bản ảnh nhỏ dần mỗi phút. Muốn tạo ngay một lần:
     Windows : php\php.exe index.php cli tao_anh_nho
     macOS   : php index.php cli tao_anh_nho
